# Test Signal: TestRelic FDE Intern Assignment

Test Signal is a small Python CLI for a 12-person SaaS team whose Playwright reports are buried in CI artifacts. It reads Playwright JSON or CTRF results, identifies hard failures and likely flaky tests, prints a plain-English summary, and can upload CTRF-compatible results to TestRelic.

## Setup

```bash
npm install
npm run analyze
```

That prints a customer-friendly summary from the included Playwright fixture. For a real project, point the CLI at the JSON report generated by Playwright:

```bash
npx playwright test --reporter=json
python3 -m test_signal analyze --report ./test-results/playwright-report.json
```

## TestRelic Integration

The Playwright config includes the `@testrelic/playwright-analytics` reporter when `TESTRELIC_API_KEY` is present.

```bash
export TESTRELIC_API_KEY=your_key_here
npm test
```

To demonstrate the failure-to-insight loop, run the intentional failure separately:

```bash
RUN_INTENTIONAL_FAILURE=1 npm test -- tests/intentional-failure.spec.js
```

The recommended upload path is the TestRelic Playwright reporter. If you are given a direct CTRF REST endpoint, the CLI can post the normalized payload too:

```bash
export TESTRELIC_API_URL=https://your-testrelic-ctrf-endpoint
python3 -m test_signal analyze --report ./tests/fixtures/playwright-report.json --upload
```

Use `--dry-run` to validate the upload path without a key:

```bash
python3 -m test_signal analyze --report ./tests/fixtures/playwright-report.json --upload --dry-run
```

## What The Tool Tells A Developer

Example output:

```text
Ran 4 tests: 3 passed, 1 failed, 0 skipped.
Recommendation: 1 test failed. Start with the first failure because it is blocking release confidence.
Plain English: The page showed different text than the test expected. Check whether the product copy changed or the UI is rendering the wrong state.
```

## CI

The included GitHub Actions workflow runs `npm test` and will send results to TestRelic when `TESTRELIC_API_KEY` is configured as a repository secret.
